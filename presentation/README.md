# حزمة العرض التقني

هذه الحزمة مصممة لتقديم تطبيق **في ظلال القرآن** أمام فريق تقني خلال 45-60 دقيقة، بهدف إظهار فهم القرارات والمعمارية، لا مجرد استعراض الواجهة.

## الملفات

| الملف | الاستخدام |
|---|---|
| `slides.html` | شرائح RTL مستقلة، تعمل مباشرة في المتصفح بلا build إضافي |
| `demo-script.md` | سيناريو الديمو الحي، التوقيت، الأوامر، ونقاط فتح الكود |
| `qa-guide.md` | 32 سؤالاً متوقعاً مع إجابات قصيرة ومراجع دقيقة |

## تشغيل الشرائح

من جذر المشروع:

```bash
xdg-open presentation/slides.html
```

أو افتح الملف مباشرة في أي متصفح حديث.

| المفتاح | الوظيفة |
|---|---|
| `ArrowRight` / `Space` | الشريحة التالية |
| `ArrowLeft` | الشريحة السابقة |
| `Home` / `End` | البداية / النهاية |
| `O` | فهرس الشرائح |
| `N` | ملاحظات المتحدث |
| `Escape` | إغلاق الفهرس أو الملاحظات |

يوجد زر ملء الشاشة في أسفل العرض، كما يدعم العرض اللمس على الهاتف. يتم احترام `prefers-reduced-motion`، وتوجد أنماط طباعة منفصلة إذا احتجت نسخة ورقية.

## ترتيب الاستخدام

1. استخدم الشرائح `01-12` لبناء القصة والنموذج الذهني.
2. عند شريحة «فاصل الديمو»، انتقل إلى المتصفح واتبع `demo-script.md`.
3. عد إلى الشرائح `14-25` للغوص في الحالة، المعالجة، PWA، الاختبارات، والمقايضات.
4. استخدم `qa-guide.md` كخريطة مراجع أثناء الأسئلة، لا كنص تقرأه حرفياً.

## فحص سريع قبل التقديم

```bash
pnpm run lint
pnpm test
pnpm run build
pnpm run start
```

اختبار PWA يحتاج نسخة production عبر `pnpm run start`؛ فهو معطل في `dev` عمداً. وتحتاج تجربة المزامنة الناجحة إلى متغيرات Supabase المضبوطة، وإلا فاعرض عقد الطلب ومسار الفشل بصدق كما يشرح السيناريو.
